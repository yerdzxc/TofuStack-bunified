# TofuStack-bunified Plan

## Repo Name
```
TofuStack-bunified
```

## Description
```
TofuStack-bunified - SvelteKit + Hono + Bun Native Auth Starter

A scalable, production-ready SvelteKit starter built entirely with Bun:
- 🔐 PASETO v4 Auth: Password + Magic Link login
- ⚡ Bun Native: password hashing, UUID, S3, HTTP
- 🗄️ Drizzle ORM + PostgreSQL
- 🎫 Redis (bun-redis) for caching & rate limiting
- ⚡ Hono API
```

---

## Bun Native Replacements

| Replace | Current | Bun Native |
|---------|---------|------------|
| Password Hashing | argon2 | `Bun.password.hash/verify` |
| UUID Generation | nanoid | `crypto.randomUUID()` |
| S3/Storage | minio | `bun:s3` or `@aws-sdk/client-s3` |
| Date Parsing | dayjs | Native `Date` |
| HTTP Fetch | node-fetch | Native `fetch()` |

## Auth Flow

```
┌─────────────────────────────────────────────────────┐
│  Password Login                                     │
│  POST /api/iam/login                               │
│  { email, password } → PASETO tokens              │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│  Magic Link (Passwordless)                         │
│  POST /api/iam/login/request → Code to email       │
│  POST /api/iam/login/verify → PASETO tokens        │
└─────────────────────────────────────────────────────┘

┌─────────────────────────────────────────────────────┐
│  Token Refresh                                     │
│  POST /api/iam/tokens/refresh                      │
│  (refresh token in HTTP-only cookie)              │
└─────────────────────────────────────────────────────┘
```

---

## Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | /api/iam/register | Register with email + password |
| POST | /api/iam/login | Login with email + password |
| POST | /api/iam/login/request | Request magic link code |
| POST | /api/iam/login/verify | Verify magic link code |
| POST | /api/iam/tokens/refresh | Refresh access token |
| POST | /api/iam/tokens/logout | Logout |
